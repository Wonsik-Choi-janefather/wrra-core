# Changelog

All notable changes to WRRA Core and its repository packaging are recorded here.

## [1.0.0] — 2026-09-07

### Frozen

- Defined Minimum Viable Computation, Common Carrier, and Phenotype as the three constitutional invariants.
- Fixed the Present, Ownership, Boundary, Renderer, Record/Ledger, and Fail-Closed principles.
- Separated the invariant Core from changeable Domain Profiles.
- Recorded the application lineage in physics, mathematics, biology, cells, artificial intelligence, embodied agents, economics, meteorology, and methodology.
- Added minimum conformance conditions and a standard Domain Profile template.

Core 1.0 remains unchanged when a Domain Profile is revised, succeeds, fails, or adopts improved external theory and data. A Core revision is considered only when a constitutional invariant or required execution element itself changes.
